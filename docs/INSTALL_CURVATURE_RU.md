# Smart Skin 0.0.27-p08e1n6 — установка и пользовательский тест

Используйте единственный установочный ZIP из успешного Windows GitHub Actions run для указанного final commit. Архив исходников, recovery и test-report не являются установщиками.

1. Закройте все окна Rhino. Полностью распакуйте install ZIP в отдельную папку. В корне должны находиться `INSTALL.cmd`, `UNINSTALL.cmd`, `manifest.json`, `build-info.txt` и каталог `net48`.
2. Запустите `INSTALL.cmd` и дождитесь `SMARTSKIN_INSTALL PASS`. Установка не требует прав администратора и не запрещает административный токен текущего пользователя. Rhino автоматически не запускается.
3. Откройте Rhino и выполните `SmartSurfaceVersion`: версия **0.0.27-p08e1n6**, commit из `build-info.txt` и manifest проверенного пакета.
4. Нажмите существующую кнопку Smart Skin или выполните **`SmartSurfaceBuild`**. Выберите исходный замкнутый набор рёбер.
5. Дождитесь preview и результатов проверок. Текущий режим явно обозначен **«стыковка без гарантии плавности»**. После осмотра подтвердите отдельным Enter / Space / правым щелчком. Esc или закрытие окна отменяет добавление.
6. После добавления проверьте один Undo, затем Redo. Добавляется только новый колпачок; исходные родители сохраняются отдельными объектами. Полная копия объединённого тела в документ не добавляется.
7. Сохраните полный TXT в предложенную папку и передайте его вместе с результатами проверки. `SmartSkinNativeReport` повторяет сохранение последнего отчёта в этой сессии без пересчёта.

Это сборка для пользовательского тестирования. Успешная стыковка Join не гарантирует плавность G1/G2; такую плавность текущий native-путь не обещает. Подробный контракт и пределы проверки: `P08E1N6_NATIVE_BUILD.md`.

## Команды

- `SmartSurfaceBuild`: текущий быстрый native-путь, проверка выбранных швов, preview и подтверждение нового cap.
- `SmartSkinNativeCompare`: отдельная диагностика на копиях; не добавляет и не заменяет объекты.
- `SmartSkinNativeReport`: сохранение последнего полного TXT в выбранную папку.
- `SmartSurfaceBuildPython`: прежний экспериментальный U/V-конструктор. Он может быть медленным и использует Rhino CPython с закреплёнными NumPy/SciPy/mpmath. Основная кнопка не запускает его автоматически.
- `SmartSurfaceBuildLegacy`: более ранний маршрут, сохранённый для сравнения.

В новом native preview нет неработающих слайдеров. Изменение формы ползунками из старого Python-инструмента не переносилось в этот пользовательский тест.

## Установочный контракт

Windows x64, Rhino 8.21+ в ветке8, .NET Framework4.8/net48 пакет. Rhino может работать на другом поддержанном runtime; это отдельная характеристика.

Регистрация HKCU, фиксированный GUID, `%LOCALAPPDATA%\SmartSkin\Rhino8\current`. При обновлении заменяются только известные файлы Smart Skin. Чужие файлы, панели, HKLM-регистрации и системные настройки не меняются. Не меняйте UAC или учётную запись ради установки.

Ошибка после начала замены восстанавливает прежние файлы и пользовательскую регистрацию. Если восстановление неполно, журнал явно указывает оставшиеся данные. При ошибке пришлите полный установочный журнал и результат `SmartSurfaceVersion`; не удаляйте общие настройки Rhino вручную.

Для удаления закройте Rhino и выполните `UNINSTALL.cmd` из пакета. Он снимает активную регистрацию и удаляет известные файлы плагина, сохраняя чужие файлы.

## Пределы проверки

Windows CI проверяет сборку, тесты, целостность пакета и реальные сценарии установки/удаления. Он не запускает лицензированный Rhino. Работа окна, клавиш подтверждения, Undo/Redo, новых проверок швов и фактическое время подтверждаются этим полевым тестом.

Если проверка блокирует добавление, сохраните TXT с причиной. Команда не должна обходить отказ, менять допуск или автоматически переходить к медленному конструктору. Отчёты сохраняются локально и не отправляются автоматически.
