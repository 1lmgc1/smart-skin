# P08D1B-FIELD01: installed field review, not a solver release

The user explicitly requested a new field package with install.cmd after D1B form rejection. This delivery makes the saved rejected proposals inspectable; it does not change their acceptance statuses or claim that they are repaired production geometry. The production RHP/P07F2, existing toolbar, .NET runtime settings and solvers remain untouched.

The private kit contains a comparison .3dm (ten unchanged original objects, one C4 baseline cap, and three three-face D1B proposals), a case/provenance manifest and these scripts. Private coordinates, source UUIDs and .3dm files are deliberately absent from this public repository. No Python/NumPy/SciPy installation is required on the user's machine. Rhino runs the user entry script with IronPython; developer test files are not shipped.

install.cmd checks Rhino is closed and payload hashes match, stages an immutable per-user release under LocalAppData/SmartSkin/Field, creates a desktop shortcut and launches a fresh working copy of the comparison. No process termination, production registry changes or RHP replacement. launch.cmd and uninstall.cmd are included. Uninstall retains reports and working model copies. The installer uses a process-local ExecutionPolicy override, never changes policy persistently.

The modeless window switches only prepared field layers. The selected variant is the sole visible alternative. Geometry is not built anew or accepted by this panel. Ordinary Rhino Zebra remains available on the separate working document. The Check button runs native Join on copies for the displayed case, including source-interval chain coverage and the two internal cap/cap seam chains. It separately reports pre-Join cap-to-source gap, post-Join common-edge-to-source gap and both lifted trim-image trajectories. Internal normal/shape checks are finite samples; they are not global certificates. External G2 and parent/self intersections are explicitly NOT_CERTIFIED/NOT_RUN in this delivery. No prior C4 Join result transfers to D1B.

Reports are one new UTF-8 file per session/check, flushed record-by-record and completed with a byte-verified checksum footer. No save-dialog retry loop. Cancellation is observed between supported native operations; native calls are not forcibly aborted. Changed/missing prepared geometry stops diagnostics rather than silently rebinding it.

Validation boundary: CPython helper tests, Windows PowerShell installer helper tests, RhinoCommon API signature compilation and real IronPython 2.7 syntax compilation. A successful CI is NOT a running Rhino UI test or a new native Join result. Private model export/readback and source-preservation checks are performed locally. Field startup, UI and native geometry still require the user's actual Rhino run.
