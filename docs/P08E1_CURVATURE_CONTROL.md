# P08E1 — экспериментальный полный цикл и управление плечами

Текущий runtime: **0.0.16-p08e1f2**. Геометрический контракт P08E1 сохранён. База патча: ветка `p08d2-topology-assist`, коммит `ec8b54b8286e4dafad7cc1b90b01b14a739d0e92`.

## Что делает эта версия

Одна кнопка Smart Skin запускает полный цикл: выбранные исходные naked Brep edges → проверка поддерживаемого семейства → две семьи новых NURBS-направляющих → новая многопатчевая оболочка → одно живое окно управления формой.

Это **экспериментальный конструктор ограниченного семейства**, а не универсальный заполнитель произвольного отверстия. Он не подменяет новый алгоритм stock CreatePatch или настройкой допуска MatchSrf. Геометрия строится из выбранных в текущем документе исходников; в комплекте нет пользовательской модели, её координат, ID или заранее рассчитанной оболочки.

## Поддерживаемые исходники

Выберите полный замкнутый цикл из 4–16 исходных naked Brep edges. Нужны:

- две противоположные зеркальные полиномиальные боковые поверхности с естественными рёбрами, согласованными native control nets и аффинным соответствием параметров;
- одна верхняя цепь, лежащая на общей плоской родительской грани: кривые плечевые участки и прямой центральный участок;
- одна нижняя прямая цепь на родителях с параллельными поперечными образующими и совместимыми физическими производными сечения;
- однозначные пересечения пяти поперечных сечений и монотонное соответствие продольным станциям.

Рациональные верхние кривые сохраняются в однородной форме вместе с весами и исходными узлами. Вес, близкий к единице, не заменяется единицей. Рациональные боковые поверхности, неподдерживаемая степень, несовпадающие зеркальные базисы, неоднозначные ветви и слишком сложные входы отклоняются с кодом причины. Это ожидаемый отказ, а не повод изменять оригинал.

Пять поперечных профилей, девять продольных станций, доля внутренней полуширины 0.85 и доля плечевого параметра 0.2 — объявленные безразмерные проектные настройки прототипа. Они вычисляются в системе координат исходной геометрии; положение, поворот и масштаб модели не зашиты. Все исходные knot spans сохраняются в проверках и разбиении.

## Крутилка Shoulder curvature

Диапазон фактора `h`: **0.50–1.50**, исходное значение **1.00**. Это фактор длины новых плечевых касательных ручек:

- первая поперечная производная масштабируется на `h`;
- нормальная составляющая второй — согласованно с `h²`;
- позиции исходных границ и геометрические условия присоединения остаются фиксированными;
- новые направляющие и поверхности пересчитываются из одного общего поля; обе стороны меняются согласованно.

Значение не является прямым заданием кривизны в 1/мм. Уменьшение ручки может выровнять плечо, но монотонное улучшение всей поверхности не гарантируется. Окно показывает реально измеренную максимальную кривизну, минимальный Jacobian, ошибки нормалей/оператора кривизны и остаточные проблемные интервалы.

Предварительно строится проверенное квадратичное поле коэффициентов. Каждое новое положение крутилки повторно проверяется. Невалидная геометрия не принимается: окно возвращает крутилку и изображение к последнему прошедшему значению и явно сообщает отказ.

## Рабочий порядок

1. Закройте Rhino и запустите **INSTALL.cmd** из полностью распакованного комплекта. Установщик сам Rhino не запускает.
2. Откройте Rhino 8.21 или новее и документ. При первом запуске Rhino ScriptEditor и CPython могут инициализироваться и загрузить закреплённые зависимости с PyPI. Нужен доступ к сети; повторная установка Rhino не требуется.
3. Нажмите единственную кнопку Smart Skin. Выберите native edge subobjects всего поддерживаемого отверстия; нажмите Enter.
4. Дождитесь первичного построения. Двигайте Shoulder curvature и оценивайте новый результат. В превью документ не меняется.
5. **Enter / Space / правая кнопка** принимают показанный результат после проверки текущего значения. **Esc** или закрытие окна отменяют работу. Отдельных кнопок Accept/Cancel нет.
6. Принятие добавляет только новые native NURBS-патчи и направляющие одним Undo. Исходные объекты не заменяются, не скрываются и не удаляются. Если источник изменился во время превью, принятие блокируется.

## Что означает PARTIAL

В исходных угловых условиях возможна несовместимость непрерывности. Проверка не прячет конечные интервалы рядом с углами. Кроме верхних участков, отчёт показывает внеактивные концевые участки боковых стыков. На них ошибка нормали может быть большой даже при точном совпадении исходных граничных кривых.

**PARTIAL не означает полный G2.** Экспериментальный результат можно явно принять, когда обязательные проверки активного бокового диапазона, внутренних швов, нижнего родителя, граничных положений и регулярности прошли, а оставшиеся ограничения показаны в окне. При фатальном нарушении превью не принимается. Native Join исходного тела, глобальная самопересекаемость и отсутствие столкновений со всем документом здесь не сертифицируются.

Исторические ограниченные маршруты P07 доступны только командой `SmartSurfaceBuildLegacy`; дополнительной кнопки нет. Новый основной маршрут не переключается на них скрыто.

## Ограничения проверки

- **VERIFIED:** автоматические тесты геометрического ядра, извлечения семейства и состояния превью; сборка net48; проверка manifest/hash/version; независимое чтение NURBS через openNURBS при доступности такого теста.
- **STATICALLY CHECKED:** RhinoCommon/Eto API и командный вход ScriptRunner/ScriptEditor, контракт одной кнопки, source-proof и обратимые транзакции установщика.
- **NOT VERIFIED:** запуск GUI Rhino, фактическое взаимодействие мышью/клавиатурой в Rhino, его native Join, загрузка CPython внутри установленного Rhino и Windows registry/CMD lifecycle в Linux-среде разработки. Мок-тесты этих проверок не заменяют.

Точный отчёт выполненных тестов сопровождает соответствующую сборку. Не переносите статус проверки с одной версии или положения крутилки на другое.

## Установка и удаление

Используйте [текущую инструкцию для exact-CI install ZIP](INSTALL_CURVATURE_RU.md). Установка вновь использует стабильный current/HKCU-контракт, а UNINSTALL.cmd действительно удаляет плагин. Исходный архив не является install kit. Правила этой коррекции описаны в [P08E1F2](P08E1F2_PIPELINE_REPAIR.md).

Зависимости Python: `numpy==1.26.4`, `scipy==1.13.1`, `mpmath==1.3.0`. Установщик не меняет настройки безопасности, Rhino runtime или системный Python.

Официальный командный вход: [McNeel ScriptEditor macros](https://developer.rhino3d.com/en/guides/scripting/advanced-scripteditor-macros/).
